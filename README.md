
**URL**: ufdr.lovable.app
AI-powered web application for analyzing UFDR (Universal Forensic Extraction Device Report) data.
Built using Lovable to provide an intuitive interface for uploading, parsing, and extracting insights from mobile forensic reports.

🚀 Overview

UFDR AI Analysis App helps investigators, researchers, and students quickly interpret forensic extraction reports by automatically:

Parsing UFDR files (HTML / XML / JSON)

Extracting structured evidence data

Detecting key artifacts (calls, messages, media, contacts)

Generating AI-based summaries and insights

Visualizing forensic data

The app is built using the Lovable AI app builder, enabling rapid development of AI-enabled web apps without heavy backend coding.

✨ Features

📂 Upload UFDR report files

🔎 Automatic report parsing

💬 AI-generated case summary

📊 Evidence categorization

🧾 Timeline extraction

📱 Clean Lovable UI

☁️ Deployable as web app

🧠 How It Works

User uploads UFDR report

App extracts structured forensic data

AI analyzes content

Insights & summary displayed
